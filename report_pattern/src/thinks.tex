\section{Выводы}
Выполнив седьмую лабораторную работу по курсу \enquote{Дискретный анализ}, я изучил алгоритм динамического программирования для подсчета палиндромных подпоследовательностей в строке.

Основные результаты работы:
\begin{itemize}
\item Реализован алгоритм динамического программирования с использованием двумерной таблицы состояний для подсчета палиндромных подпоследовательностей
\item Разработана эффективная схема переходов между состояниями с учетом принципа включения-исключения
\item Проведено сравнение производительности с наивным рекурсивным подходом, показавшее значительное преимущество DP-алгоритма
\item Изучены особенности применения динамического программирования для задач на строках и подсчета комбинаторных объектов
\end{itemize}

Алгоритм демонстрирует эффективность использования мемоизации для избежания повторных вычислений, что особенно важно при работе с экспоненциально растущими подзадачами. Временная сложность O(n²) делает алгоритм применимым для строк значительной длины.
