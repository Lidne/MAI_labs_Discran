\section{Выводы}
Выполнив пятую лабораторную работу по курсу \enquote{Дискретный анализ}, я изучил алгоритм построения суффиксного массива и его применение для эффективного поиска образцов в тексте. 

Основные результаты работы:
\begin{itemize}
\item Реализован алгоритм построения суффиксного массива с использованием стандартной сортировки и лексикографического сравнения суффиксов
\item Разработан метод бинарного поиска для нахождения всех вхождений образца в текст за время O(log n)
\item Проведено сравнение производительности с наивным алгоритмом поиска, показавшее значительное преимущество при множественных запросах
\item Изучены особенности работы с суффиксными структурами данных и их практическое применение
\end{itemize}

Алгоритм демонстрирует эффективность использования предобработанных структур данных для ускорения поисковых операций, что особенно важно при работе с большими объемами текстовых данных.
