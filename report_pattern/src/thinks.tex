\section{Выводы}
Выполнив восьмую лабораторную работу по курсу \enquote{Дискретный анализ}, я изучил алгоритм размена заданной суммы с использованием жадного подхода для специального случая системы номиналов.

Основные результаты работы:
\begin{itemize}
\item Реализован жадный алгоритм размена суммы с использованием структуры Coin для хранения номинала и количества монет
\item Разработана эффективная схема последовательного подбора наибольших номиналов с временной сложностью O(N)
\item Проведено обоснование неприменимости жадного алгоритма для произвольных номиналов на конкретном контрпримере
\item Изучены особенности применения жадных алгоритмов для задач оптимального размена и условия их применимости
\item Исследована производительность алгоритма на различных входных данных
\end{itemize}

Алгоритм демонстрирует эффективность использования жадного подхода для задач размена с системой номиналов, заданной степенями некоторого основания. Для таких систем жадный алгоритм гарантирует оптимальное решение, что делает его применимым для практических задач. Временная сложность O(N) делает алгоритм быстрым даже для больших значений N и M.
