\section{Описание}
Основная идея алгоритма решения задачи состоит в использовании динамического программирования для подсчета количества палиндромных подпоследовательностей в заданной строке. Алгоритм строит двумерную таблицу состояний, где dp[l][r] представляет количество непустых палиндромных подпоследовательностей в подстроке s[l..r].

Алгоритм состоит из следующих этапов:
\begin{enumerate}
\item \textbf{Инициализация:} Создается таблица dp[n][n], где n — длина входной строки.
\item \textbf{Базовые случаи:} Для каждой позиции i устанавливается dp[i][i] = 1, так как одиночный символ является палиндромом.
\item \textbf{Заполнение таблицы:} Для каждой подстроки s[l..r] вычисляется количество палиндромных подпоследовательностей:
\begin{itemize}
\item Если s[l] == s[r], то dp[l][r] = dp[l+1][r] + dp[l][r-1] + 1
\item Иначе dp[l][r] = dp[l+1][r] + dp[l][r-1] - dp[l+1][r-1]
\end{itemize}
\end{enumerate}

Преимущество данного подхода заключается в том, что каждое состояние вычисляется только один раз, что обеспечивает временную сложность O(n²) и пространственную сложность O(n²).

\section{Исходный код}
Программа считывает строку и выводит количество способов вычеркивания символов для получения палиндромной подпоследовательности.

\begin{lstlisting}[language=C++, basicstyle=\small\ttfamily]
#include <iostream>
#include <vector>
#include <string>

int main() {
    std::string s;
    if (!(std::cin >> s)) {
        return 0;
    }

    const int n = static_cast<int>(s.size());
    if (n == 0) {
        std::cout << 0 << '\n';
        return 0;
    }

    std::vector<std::vector<unsigned long long>> dp(n, 
        std::vector<unsigned long long>(n, 0));

    for (int len = 1; len <= n; ++len) {
        for (int l = 0; l + len - 1 < n; ++l) {
            int r = l + len - 1;
            if (l == r) {
                dp[l][r] = 1;
            } else if (s[l] == s[r]) {
                dp[l][r] = dp[l + 1][r] + dp[l][r - 1] + 1;
            } else {
                dp[l][r] = dp[l + 1][r] + dp[l][r - 1] - dp[l + 1][r - 1];
            }
        }
    }

    unsigned long long result = dp[0][n - 1];
    std::cout << result << '\n';
    return 0;
}
\end{lstlisting}
