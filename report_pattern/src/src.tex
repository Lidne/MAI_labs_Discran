\section{Описание}
Основная идея алгоритма решения задачи состоит в использовании жадного подхода для размена заданной суммы с наименьшим количеством монет. Алгоритм последовательно подбирает наибольшие возможные номиналы монет.

Алгоритм состоит из следующих этапов:
\begin{enumerate}
\item \textbf{Инициализация:} Создается массив монет с номиналами $p^0, p^1, ..., p^{N-1}$ и счетчиками количества каждой монеты.
\item \textbf{Заполнение номиналов:} Для каждого индекса i вычисляется номинал монеты как $p^i$.
\item \textbf{Размен суммы:} Начиная с наибольшего номинала, для каждого номинала вычисляется максимально возможное количество монет данного номинала, которое можно использовать для размена оставшейся суммы. Оставшаяся сумма уменьшается на соответствующее значение.
\end{enumerate}

Преимущество данного подхода заключается в том, что для специального случая, когда номиналы являются степенями некоторого основания p, жадный алгоритм гарантирует оптимальное решение с временной сложностью O(N).

\section{Обоснование неприменимости жадного алгоритма в общем случае}
В общем случае, когда номиналы могут быть произвольными, жадный алгоритм не всегда дает оптимальное решение. 

\textbf{Контрпример:} Рассмотрим набор монет с номиналами \{1, 3, 4\} и сумму 6. Жадный алгоритм выберет: 4 (1 монета) + 1 + 1 (2 монеты) = 3 монеты. Однако оптимальное решение: 3 + 3 (2 монеты).

Для произвольных номиналов требуется алгоритм динамического программирования, где для каждой суммы от 1 до M хранится минимальное количество монет, необходимое для ее размена. Временная сложность такого алгоритма O(N × M), что делает его применимым для произвольных входных данных.

\section{Исходный код}
Программа считывает параметры N, p и сумму M, затем выводит количество монет каждого номинала для размена суммы.

\begin{lstlisting}[language=C++, basicstyle=\small\ttfamily]
#include <cmath>
#include <iostream>
#include <vector>

struct Coin {
    unsigned int value;
    unsigned int count;
};

void printShi(std::vector<Coin> arr) {
    for (auto& coin : arr) {
        std::cout << coin.count << std::endl;
    }
}

int main() {
    unsigned int N, p, M;
    std::cin >> N >> p >> M;
    std::vector<Coin> arr(N);
    for (size_t idx = 0; idx < N; ++idx) {
        arr[idx].value = pow(p, idx);
    }

    size_t i = N - 1;
    while (M != 0) {
        arr[i].count = M / arr[i].value;
        M -= arr[i].count * arr[i].value;
        --i;
    }
    printShi(arr);
    return 0;
}
\end{lstlisting}
