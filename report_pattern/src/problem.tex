\CWHeader{Лабораторная работа 7}

\CWProblem{
Требуется разработать программу для подсчета количества способов вычеркивания символов из заданной строки так, чтобы полученная подпоследовательность была палиндромом.

Формат ввода: Задана одна строка S (|S| <= 100), состоящая из прописных букв латинского алфавита.

Формат вывода: Необходимо вывести одно число — количество способов вычеркивания символов для получения палиндромной подпоследовательности. Способы, отличающиеся только порядком вычеркивания символов, считаются одинаковыми.

Алгоритм: Динамическое программирование с использованием двумерной таблицы состояний.
}
