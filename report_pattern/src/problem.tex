\CWHeader{Лабораторная работа 8}

\CWProblem{
Требуется реализовать программу, находящую длину кратчайшего пути в взвешенном ориентированном графе с отрицательными весами рёбер (при условии отсутствия отрицательных циклов) при помощи алгоритма Беллмана--Форда.

Формат ввода: в первой строке заданы $n$, $m$, $start$, $finish$ ($1 \le n \le 3\cdot 10^5$, $1 \le m \le 10^5$). Далее следуют $m$ строк с описанием рёбер: $u$, $v$, $w$ ($-10^9 \le w \le 10^9$), где $u$ — начало, $v$ — конец, $w$ — вес.

Формат вывода: одно число — длина кратчайшего пути от $start$ до $finish$, либо строка \enquote{No solution}, если путь не существует.

Алгоритм: Беллман--Форд с оптимизацией раннего останова и проверкой достижимости целевой вершины.
}
