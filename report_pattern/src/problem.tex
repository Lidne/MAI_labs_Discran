\CWHeader{Лабораторная работа 8}

\CWProblem{
Требуется разработать программу для размена заданной суммы M с использованием наименьшего количества монет.

Формат ввода: На первой строке заданы два числа, N и p>1, определяющие набор монет некоторой страны с номиналами $p^0, p^1, ..., p^{N-1}$. На второй строке задана сумма M <= $2^{32}-1$.

Формат вывода: Необходимо вывести для каждого i-го номинала на i-ой строке количество участвующих в размене монет.

Требуется обосновать, почему жадный выбор неприменим в общем случае (когда номиналы могут быть любыми) и предложить алгоритм, работающий при любых входных данных.

Алгоритм: Жадный алгоритм с началом выбора с наибольшего номинала.
}
